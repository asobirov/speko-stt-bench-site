speko-stt-bench
How to read this. Each provider transcribed the same FLEURS English clips times: once clean, and once for each degraded version (white/crowd/TV noise mixed in at 10 dB = speech clearly louder than the noise, or 0 dB = speech and noise equally loud; "phone" = 300–3400 Hz band, 8 kHz, μ-law, like a normal phone call).
WER = % of reference words the provider got wrong (substituted + deleted + inserted). "vs clean" = how many percentage points worse than the same provider on the same clean clips. For example, 5% → 12% shows as +7 pts, so 7 more words wrong out of every 100. These are point estimates, computed by the same code as RESULTS.md, which also has the confidence intervals. Click any cell to open those clips.
Click a clip to listen and see each provider's transcript diffed against the reference.
Batch latency study only (warm-up calls excluded): one request at a time, the same clips for every provider, rounds. Each dot is one call. Lines mark p50 (half the calls were faster) and p95 (only 1 in 20 was slower). A yellow dot means the call had to open a new connection (TCP+TLS inside the timer). Grey = not recorded (two-step providers: upload, then transcribe).
